# Projeto Netflix

Projeto front-end inspirado na interface da Netflix.

A aplicação possui diferentes telas que simulam parte da experiência de navegação da plataforma.

## Funcionalidades

- Tela de login
- Seleção de perfil
- Página inicial
- Interface de reprodução
- Layout responsivo

## Tecnologias

- HTML
- JavaScript
- Tailwind CSS

## Objetivo

Projeto desenvolvido para praticar construção de interfaces modernas utilizando Tailwind CSS.
